## 1. 三步跑起来

```bat
:: 第一步：确认系统能看见散热器
fanf9ctl.exe -list
```

期望输出里有类似：

```
d1:03:d1:xx:xx:xx  LEGION_F9_BT  \\?\bthle#dev_d102d10fafee#...
```

如果没有，**先去 Windows「设置 → 蓝牙和其他设备」里配对散热器**（名字是 `LEGION_F9_BT`，旧批次叫 `Viqsyx_F9_BT`）。
BLE 的 GATT 接口只对"系统已知/已配对"的设备开放。

```bat
:: 第二步：确保官方 LEGION EDGE 已经退出（它会占着设备的句柄）
:: 第三步：运行
fanf9ctl.exe
```

程序会：
1. 打开一个**原生窗口**（Win32 + GDI 自绘，不依赖浏览器；程序是 GUI 子系统，双击不会出现黑框；看日志加 -debug）；
2. 600 ms 后自动连接名字里含 `F9_BT` 的设备；
3. 发握手 `ee 03 22`，再读一次灯光配置 `ee 05 0f`；
4. 之后每 3 秒轮询转速，每 6 秒重发一次当前设置。

窗口里「风扇转速」开始跳动，就说明整条链路通了。
窗口没出来就先跑 `fanf9ctl.exe -diag` 看蓝牙这一层通没通。

## 2. 真机上可能遇到的问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `连接` 点了没反应 / 报 `CreateFile 失败` | 官方 App 或 Windows 蓝牙服务占着句柄 | 退出 LEGION EDGE，必要时重启蓝牙 |
| 枚举能成，但读/写/订阅全报 `HRESULT 0x80070001` | 打开了总接口 `\\?\BTHLE\Dev_<地址>`——它只能读缓存 | 已修：现在自动打开按服务拆分的 `\\?\BTHLEDevice\{服务UUID}_Dev_…` 节点；`-diag` 会逐步打印 HRESULT |
| 连上了，但转速一直是 `--`，日志里只有 TX 没有 RX | 通知特征选错 | 展开「高级 / 调试」→ 看「发现的服务 / 特征」→ 把 `props` 里有 `notify` 的 UUID 填进 `config.json` 的 `notifyCharUUID` |
| 写不进去 / 报 HRESULT | 该特征只支持 write-without-response | `config.json` 里 `"writeWithoutResponse": true` |

日志面板里每一行都是十六进制，直接能和 `官方 App 的 BleC.log` 对照。

## 3. 已经确认的（2026-10-28，本机 LEGION_F9_BT）

- **GATT 接口**：必须用 `\\?\BTHLEDevice\{19090909-0a0a-0b0b-0c0c-0d0d0e0e0f0f}_Dev_…` 这个服务节点。
  写特征 `19190909-…`、通知特征 `19290909-…`，20 字节帧，读 / 写 / 订阅都正常。
- **转速**：`ee 1a 06 00 00 01 LL HH`，`(HH<<8|LL)>>2`。
- **设置帧字段**（点官方 App 逐字节标定）：
  - `data[1]` 灯光模式：3=恒亮，2=呼吸，1=渐变
  - `data[2]` 亮度：0..9
  - `data[13]` 风扇档位：0..3（安静/平衡/野兽/超能），实测转速 1291/2027/2450/3060
  - data[5]：多色标志，只有渐变置 1（置 1 时单色 RGB 会被忽略，呼吸/恒亮置 0）
  - `data[3]`：官方恒发 2，含义未知
- **`data[0]`**：官方恒发 0；改成 1 会把档位锁死（四个档位都卡在 2031 转），不是 AI。
- **AI 模式**：官方是 **App 端闭环**——每 1–2 秒改一次档位字节 `data[13]`，`data[0]` 始终 0，
  设备只负责执行档位。本工具的「自动」用 CPU 占用率近似（温度要内核驱动，不用）。
- **温度**：F9 不上报；不装驱动的 ACPI 热区这台机器没有，所以不做温度显示。
- **重启行为**：用户设置存在 state.json，启动按它恢复并下发；data[0] 一律清成 0。
- **托盘**：关窗口缩到托盘，右键菜单 打开/开机启动/退出；**必须从普通目录运行**（低完整性标签目录下 UIPI 会禁止加托盘）。
- **开机启动**：托盘右键勾选，写 HKCU Run 项（带 `-tray` 参数），不需要管理员；`-tray` 启动只驻留托盘。
- **图标**：icon.ico 运行时嵌入（窗口/托盘），
src_windows_amd64.syso 提供 exe 文件图标。

## 4. 还没确定的

- **动态光效**：没有样本。要补的话在官方 App 里点一下，看 `BleC.log` 的 `data[1]`。
- **多色/渐变配色**：`data[9..12]` 一直是 0，没验证。
- **自动模式的曲线**：官方按温度，我们按占用率，阈值和档位映射是自己定的，可调。
